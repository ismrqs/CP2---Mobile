# CheckPoint 2 - Mobile

Desenvolver um app que permita ao usuário fazer a gestão dos gastos.

O usuário deve ser capaz de inserir um valor, adicionando ou subtraindo da sua gestão de gastos.
Todo histórico de transações deve ser apresentado na tela. Além da possibilidade de exclusão de algum item do histórico, sem afetar o cálculo do saldo total.

O app deverá apresentar cenários de sucesso, tratamento de erros comuns e uma estrutura com separação clara entre lógica e interface (UI).
